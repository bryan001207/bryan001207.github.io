🔍 What is Argus?

Argus is a simple, focused dashboard that shows you everything happening in your GitHub repositories that needs your attention. If you're an engineering lead, a tech manager, or a senior developer who needs to keep an eye on many pull requests at once, Argus saves you hours every day by putting all the important information in one clean view.

Think of it as your personal air-traffic control tower for code. Instead of clicking through hundreds of emails or notifications, you open one page and instantly see:

  • Reviews waiting on you – Pull requests where someone is waiting for your approval or feedback.
  • Merge-ready PRs – Code that has passed all checks and is ready to be merged, waiting for the final go-ahead.
  • Stale work – Old pull requests or issues that have been sitting around without updates for too long.
  • Security alerts – Critical vulnerabilities in your dependencies that need immediate attention.

All of this is displayed in a clean, easy-to-read interface that works on any screen—from your desktop monitor to your phone while you're on the go.

🖥️ What You Need

Argus is designed to work on a standard Windows computer with minimal requirements:

  • A computer running Windows 10 or 11 (64-bit recommended).
  • At least 4GB of RAM (more helps if you have many repositories).
  • A stable internet connection to access GitHub.
  • A GitHub account with access to the repositories you want to track.
  • Your own GitHub Personal Access Token (the app shows you how to create one when you first run it).

That's it! No special drivers, no command-line tools, no extra software. If you can browse the web, you can run Argus.

🛠️ Quick Help

Q: What if my antivirus warns about the downloaded file?

A: This is a common false positive for open-source apps. You can safely allow it to run. The app doesn't modify any system files—it's completely self-contained.

Q: I downloaded the file, but nothing happens when I double-click it.

A: Try right-clicking and selecting "Run as administrator." Also make sure you've extracted the file completely if you downloaded a .zip version.

Q: Do I need to install Docker or any other tool?

A: No. While the app uses Docker-friendly technology behind the scenes, the Windows version works as a standalone application. Just download and run.
